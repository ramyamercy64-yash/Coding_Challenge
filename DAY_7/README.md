# 🚕 Ride Booking Analysis

## 📌 Project Overview

This project performs a basic analysis of **ride-booking data** using Python.

Each ride record is stored as a tuple containing:

* Ride ID
* Driver Name
* City
* Fare
* Rating

The project demonstrates how Python **tuples, loops, conditional statements, `len()`, `sum()`, `max()`, and dictionaries** can be used to analyze ride data.

---

## 🎯 Objectives

The analysis covers:

1. Counting the total number of rides
2. Extracting rides from Bangalore
3. Calculating total revenue from Bangalore
4. Finding the highest-rated driver
5. Calculating the average rating for each city
