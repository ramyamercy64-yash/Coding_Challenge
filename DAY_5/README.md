# 🖥️ Help Desk Analysis

## 📌 Project Overview

This project analyzes **Help Desk / IT Support ticket data** to understand ticket volume, resolution time, recurring problems, and analyst performance.

The analysis helps identify operational patterns and provides actionable recommendations to improve **IT support efficiency and ticket resolution**.

---

## 🎯 Objectives

* Analyze ticket volume trends over time
* Calculate average ticket resolution time
* Identify high-volume periods
* Find recurring problems and common issues
* Compare analyst performance
* Identify areas that may require process improvement
* Provide actionable recommendations for the IT team

---

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning, calculations, and analysis
* **Power BI** – Dashboard and data visualization
* **SQL** – Data querying and analysis
* **GitHub** – Project documentation and version control

---

## 📊 Key Analysis

### 1. Ticket Volume Trends

Analyzed ticket volumes across:

* Dates
* Months
* Days
* Hours

This helps identify periods with higher support demand.

### 2. Resolution Time Analysis

Calculated:

* Average Resolution Time
* Minimum Resolution Time
* Maximum Resolution Time
* Resolution Time by Category
* Resolution Time by Priority

### 3. Top Problems & Root Causes

Analyzed ticket descriptions to identify:

* Frequently occurring issues
* Common keywords
* Recurring support problems
* Potential root causes

### 4. Analyst Performance

Compared analysts based on:

* Number of tickets handled
* Average resolution time
* Workload
* Support performance

provide more in-depth detail for each of the required insights. This sheet should

o Sheet 4: "Recommendations": A final sheet with a clear, bulleted list of your 
actionable recommendations for the IT Director. For example: "Implement an 
automated password reset tool to reduce the volume of 'Access' tickets."
