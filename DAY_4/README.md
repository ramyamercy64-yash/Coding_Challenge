# 🏦 Banking Data Analysis – Power BI

## 📌 Project Overview

This project analyzes banking data using **Power BI** to understand customer profiles, transaction activity, loan performance, and customer profitability.

The project includes interactive dashboards with **KPIs, charts, slicers, drill-through pages, tooltips, bookmarks, conditional formatting, and What-If analysis**.

## 🎯 Project Objectives

* Analyze customer demographics and account information.
* Understand monthly transaction trends.
* Analyze transaction activity by day and hour.
* Study loan status and loan default rates.
* Identify customers with low account balances.
* Analyze customer profitability.
* Simulate the impact of different interest rates on revenue.

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* **Power Query**
* **Excel / CSV**
* **Data Modeling**

## 📊 Dashboard Sections

### 1. Customer Overview

* Customers by Age Group and Gender
* Total Customers KPI
* Customer Balance Analysis
* Conditional formatting for balances below ₹5,000
* Slicers for Age Group, Gender, and Account Type

### 2. Transaction Analysis

* Monthly Transaction Trend
* Transactions by Day of Week and Hour of Day
* Transaction Count
* Customer Transaction History using Drill-through

### 3. Loan Performance

* Loan Status Distribution
* Loan Default Rate %
* Traffic-light KPI:

  * 🟢 Green: Below 5%
  * 🟡 Yellow: 5%–15%
  * 🔴 Red: Above 15%
* Interest Rate What-If Parameter
* Simulated Revenue and Revenue Impact

### 4. Customer Analysis

* Top Customers by Transaction Activity
* Customer Profitability Score
* Average Account Balance
* Customer-level transaction details

## 📈 Key Insights

* Customer activity can be analyzed across different age groups and genders.
* Low-balance customers can be identified using conditional formatting.
* Monthly transaction trends help identify changes in banking activity.
* Loan statuses include **Active, Default, Closed, and Unknown**.
* The Loan Default Rate KPI provides a quick view of default activity.
* The What-If parameter allows users to explore different interest-rate scenarios.
